# InsightFlow AI — Pricing and Packaging

This is fictional pricing information created for a portfolio RAG project.

## Starter Plan
For students, small teams, and demos.
- Local Markdown knowledge base
- CSV input
- Mock LLM mode
- Basic RAG retrieval
- Manual review workflow
- Local Power BI CSV export

## Professional Plan
For teams running a lightweight production workflow.
- MySQL and PostgreSQL connectors
- Markdown, PDF, and text ingestion
- LLM API integration
- Power BI export tables
- Human review status tracking
- Config-driven pipeline

## Enterprise Plan
For organizations with security and compliance needs.
- Private deployment options
- Role-based access control
- Enterprise LLM API support
- Custom vector database integration
- Scheduled pipeline execution
- Power BI Service refresh integration
- Advanced evaluation reports
- Document-level access control

## Proof of Concept Scope
A typical POC includes:
- 3 to 5 product documents
- 20 to 50 common pre-sales questions
- RAG-based answer generation
- Source references for every answer
- Human review status
- Evaluation using expected-answer test cases
